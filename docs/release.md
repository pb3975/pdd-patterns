# Public release proposal

This repository stays private until Will approves making the reviewed collection and its Git history public. Approval of this collection does not authorize website hosting. The website remains offline until Vercel credentials and launch approval are provided.

The proposed reuse license is MIT. The text in [LICENSE-MIT.proposed](LICENSE-MIT.proposed) is prepared for review. On approval, move it to the repository's top-level `LICENSE` file. Dependency licenses remain separate.

Before requesting approval:

1. Run the pinned proof tools and all semantic negative controls.
2. Check every starter after copying it outside the repository.
3. Check the agent skill structure and record its actual use.
4. Complete review and CI on the candidate commit.
5. Inspect the candidate and its history for credentials, private data, and unsupported proof claims.

The approval request must link the private repository, identify the reviewed commit, and describe the proposed license. Making Git history public cannot undo copies other people obtain.

After approval, add the approved license, check the final diff and CI, make the repository public, and verify that its landing page is accessible without authentication. Only then replace the website's held collection notice with the public link and update its publication-boundary check. Do not deploy the website as part of that source update.
